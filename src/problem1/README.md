# Sum to N

---

### Installation

Require node version >=22.12.0

```bash
npm install
```

### Run test

```bash
npm test
```

### Implementations

1. Iterative Approach (sum_to_n_a): Uses a standard for loop to accumulate the sum.

2. Mathematical Approach (sum_to_n_b): Uses the arithmetic series formula $n(n+1)/2$.

3. Recursive Approach (sum_to_n_c): Uses function recursion.
